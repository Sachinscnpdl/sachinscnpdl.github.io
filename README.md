# Sachin Poudel

Personal academic website for **Sachin Poudel**, Ph.D. candidate in Mechanical Engineering at the Silesian University of Technology.

The website presents my research profile, selected publications, projects, CV, and contact information. My work focuses on computational and data-driven materials design, including multiphysics simulations, phase-field modeling, finite element analysis, and machine learning for functional materials.

🔗 **Website:** [sachinscnpdl.github.io](https://sachinscnpdl.github.io/)  
📄 **CV:** [`public/SachinCV.pdf`](public/SachinCV.pdf)

---

## About this website

This is a lightweight React-based personal website designed for clear presentation of research, publications, and academic activities.

It includes:

- Research overview and academic profile
- Resume/CV page
- Selected publications and projects
- Responsive layout for desktop and mobile
- GitHub Pages deployment support

---

## Tech stack

- React
- React Router
- SCSS
- GitHub Pages
- GitHub Actions

---

## Run locally

```bash
git clone https://github.com/sachinscnpdl/sachinscnpdl.github.io.git
cd sachinscnpdl.github.io
npm install
npm start
```

The site will run at:

```bash
http://localhost:3000/
```

---

## Build and deploy

Create a production build:

```bash
npm run build
```

Deploy to GitHub Pages:

```bash
npm run deploy
```
